# Homebrew tap for needledrop

[needledrop](https://github.com/audiarmadhani/needledrop) is a good-looking terminal client for YouTube Music.

```sh
brew install audiarmadhani/needledrop/needledrop
```

Or tap first, then install by name:

```sh
brew tap audiarmadhani/needledrop
brew install needledrop
```

Homebrew builds it from source with Rust and installs mpv, yt-dlp, and ffmpeg.
